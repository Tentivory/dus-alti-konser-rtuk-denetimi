# Duş Altı Konser RTÜK Denetimi

> Resmî olmayan resmî kurum.  
> Su damlası yayın lisansıdır.  
> Sabun yapımcı, şampuan sponsor, havlu ise sansür kuruludur.

Bu yazılım, bir vatandaşın duş alırken şarkı söylemesini **ulusal yayın faaliyeti** kabul eder. Komşu duvarı verici anten, boru tesisatı fiber hat, buhar ise yayın sis perdesidir. Bilimsel dayanağı yoktur. Yasal dayanağı da yoktur. Buna rağmen evrak üretir.

## Ne yapar?

1. Şarkı adını alır.
2. Rastgele ama ciddi görünen bir desibel ölçer.
3. Komşu şikâyet skorunu hesaplar.
4. RTÜK kararı basar.
5. Cezayı **sabun kalıbı** cinsinden keser.

## Çalıştırma

```bash
python3 rtuk.py
```

İsteğe bağlı gizli bayrak (bulursanız bulun, yoksa yok):

```bash
python3 rtuk.py --ek-madde
```

## Anayasa gibi duran ama durmayan maddeler

- Madde 1: Duş kabini stüdyodur.
- Madde 2: Musluk açıldığı anda lisans yürürlüğe girer.
- Madde 3: Yanlış nota milli duygu sapmasıdır.
- Madde 4: Komşu kapıya vurursa bu bir jüri kararidır.
- Madde 5: Havlu ile kapatılan mikrofon sansürdür, sansür de yayındır.

## Sorumluluk reddi

Bu kod kimseyi şikâyet etmez, kimsenin suyunu kesmez, kimsenin seçimini etkilemez. Sadece buhar üretir. Buhar da geçer.
